# 排程採用簡化版 SM-2，而非完整 SM-2 或 FSRS

間隔重複的排程演算法有現成標準可用（SuperMemo 的 SM-2、Anki 現行預設的 FSRS），本專案刻意都不採用，改寫一套只保留「間隔」與「成長倍數」兩個狀態的簡化版本：新間隔 = 舊間隔 × 成長倍數，四個評分按鈕直接對應四種調整，不經過 0–5 分的品質對照表。

選擇簡化版的理由是**可讀性優先於精確度**。這是單人自用工具，排程算錯幾天的代價趨近於零，但演算法看不懂、出問題無法自己 debug 的代價很高。FSRS 的 17 個權重參數與記憶模型無法憑肉眼驗證；完整 SM-2 則有兩處源自 1987 年紙本卡片盒的歷史包袱——前兩次間隔寫死 1 天與 6 天、以及「困難」被歸類為答對因而大幅拉長間隔（熟卡按「困難」會給出 38 天，與按「好」幾乎無異，違反使用者直覺）。此處跟隨 Anki 後來的修正，將「困難」定為 ×1.2。

## Consequences

換掉演算法的成本不對稱：卡片上存的「間隔」與「成長倍數」在不同演算法下語意不同，日後若要改用 FSRS，既有複習歷史無法直接轉換，等同重新開始累積。因此這個決定實質上是單向的。
