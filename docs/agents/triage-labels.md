# Triage 標籤

這些 skill 以五個標準 triage 角色來溝通。本檔案把這些角色對應到本 repo issue tracker 實際使用的標籤字串。

| mattpocock/skills 的標籤 | 本 repo 的標籤    | 意義                     |
| ------------------------ | ----------------- | ------------------------ |
| `needs-triage`           | `needs-triage`    | 維護者需要評估這個 issue |
| `needs-info`             | `needs-info`      | 等待回報者補充資訊       |
| `ready-for-agent`        | `ready-for-agent` | 規格完整，可交給 AFK agent |
| `ready-for-human`        | `ready-for-human` | 需要人工實作             |
| `wontfix`                | `wontfix`         | 不會處理                 |

當某個 skill 提到某個角色時（例如「套上 AFK-ready 的 triage 標籤」），使用本表對應的標籤字串。

右欄可自行修改，改成你實際使用的詞彙。
