# 15 — 卡片列表：搜尋與六個時間桶，順帶把單字本管理接上來

Status: ready-for-agent
Type: enhancement
Blocked by: 06, 09

決策背景見 `../spec.md` 的〈實作順序〉。`spec.md:150` 寫著「這幾頁的票等複習畫面做完再開」——
票 `06` 與票 `09` 都收掉了，這道閘開了，這是排在後面那四頁的第一張。

## 為什麼有這張票

`mobile/app/cards.tsx` 現在是 12 行的「還沒做」。app 目前只複習得了，維護不了卡片。

**單字本管理提前，是因為它擋在前面。** 建立單字本的介面住在資料頁，那頁排第三順位。
但列表頁的零狀態、票 `16` 編輯頁的單字本下拉，兩邊都要有本才成立；手機上現在唯一建得出本的地方
是票 `06` 留的探針畫面。等資料頁等不到，所以把單字本那一區從資料頁拆出來，提前放進這張票。

2026-08-28 拍板，三題答案照著走：列表四樣功能全照搬、單字本管理併進這張票、
編輯頁那題見票 `16`。

## 要做什麼

對照 `src/ui/list-view.ts`（229 行）與 `src/ui/books-section.ts`（242 行），做出卡片列表頁。

| 部位 | 內容 |
| --- | --- |
| 搜尋 | 比對詞條、去標記後的詞條、讀音、釋義四個欄位，不分大小寫 |
| 六個時間桶 | 新卡／現在／今日／明天／本週／未來，各自展開收合，空桶顯示並標 0 |
| 排序切換 | 正序倒序，桶順序與桶內順序一起翻 |
| 單字本篩選 | 改的是 `scopes.list` 這一組，與複習、統計那兩組互不影響 |
| 卡片列 | 詞條（含振假名）、釋義、所屬單字本、實際到期日；新卡不長到期日那一欄 |
| 「共 N 張」 | 篩選發生在搜尋與分桶之前，所以 N 是範圍內的張數，不是全 app 的 |
| 單字本管理 | 新增、改名、刪除、匯入單字 |
| 零本 | 一本都沒有時另一套畫面，指向這一頁自己的「新增單字本」，不是死按鈕 |

### 純邏輯先抽進 `core/`

`groupByBucket()`、`bucketOf()`、搜尋的 `filter()` 現在住在 `src/ui/list-view.ts` 裡，
`book-filter.ts` 的 `scopeLabel()` 同理。**這幾支不碰 DOM，抽進 `core/lib/`，兩邊共用一份。**
票 `02` 的原則：邏輯層不准分岔。抽完網頁版改成從 `core/` 取，行為一個字不改，既有測試要全綠。

`mobile/ui/book-scope-sheet.tsx` 已經是通用的（吃 `books` / `selected` / `onChange`），
接上 `scopes.list` 直接能用，不要再寫第二支。它裡面那三行抄過去的 `scopeLabel()`，
這次改成從 `core/` 取。

### 搜尋框

用系統的搜尋列，不自己畫一個。往下捲收起、往上捲帶回來都交給系統。
清單頁的搜尋在 HIG 有專章（`Search fields`、`Searching`），這一頁做的時候要把對應條目
補進 `../hig-checklist.md`——那份清單刻意留成「邊做邊長」，現在五個章節裡沒有清單與搜尋。

搜尋期間的行為照網頁版：空桶藏起來、六桶全展開、清空搜尋框還原成搜尋前的收合狀態。

### 單字本管理

`addBook()`、`renameBook()`、`deleteBook()` 已經在 `core/lib/storage.ts`，判斷全在那裡，
畫面只負責把它說的話翻成看得到的字。刪除確認在 React Native 上沒有 `confirm()`，
改用 `Alert.alert()`。匯入單字要能選檔（`expo-document-picker`），
匯入結果與跳過的詞照 `books-section.ts` 的樣子畫在那一本底下。

### 探針畫面拆掉一半

單字本建得出來之後，探針上那塊建本的入口拆掉。**整支探針先留著**——
登入雲端仍然只有那裡做得到，資料頁還沒開票。

## 這張票不做的事

- **不做編輯畫面。** 那是票 `16`，這一頁點卡片列導過去，接縫留好即可。
- **不做資料頁與統計頁。** 雲端備份、金鑰、提醒、統計圖表都不在這張。
- **不改分桶、排序、搜尋比對的規則。** 抽進 `core/` 是搬家，不是重寫。
- **不動網頁版的外觀。** 與 spec〈不在範圍內〉一致。

## 已知風險

**六個桶加上搜尋列、工具列、tab bar，一頁上的 chrome 很多。** 票 `09` 接受過「底部一次兩條」，
這一頁是上面也有兩層。並排目測那一關要特別看這件事，過不了就先砍工具列那一排。
