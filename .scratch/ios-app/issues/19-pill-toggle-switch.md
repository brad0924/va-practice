# 19 — 提醒開關改成膠囊式，不要用勾的

Status: ready-for-agent
Type: enhancement
Blocked by: 09（已 done）

沒有對應的 spec 決定——外觀，維護者直接提的。

## 要做什麼

「資料」畫面上每日提醒那顆開關，從方形勾選框換成 iOS 那種左右滑動的膠囊。

現在是 `<input type="checkbox" class="toggle-check">`，配 `src/styles.css` 的三行樣式（寬高與 `accent-color`）。

## 決定

### 底下仍然是 `<input type="checkbox">`，只是換皮

用 `appearance: none` 把原生外觀拿掉，再用 `::before` / `::after` 畫出軌道與滑塊。

**不換成 `<button role="switch">`**：那要自己補鍵盤操作、`aria-checked` 的維護、以及 label 點擊要連動。checkbox 這三件事全部免費，而且 `change` 事件那段程式一個字都不必改。換掉只為了語意上更像「開關」，代價不划算。

### 只改提醒那一顆，單字本那排維持勾選框

同一頁上方「單字本」那排也是勾選框（`book-check`），這張票**不動它**。

兩者並存不是不一致，是語意不同：膠囊式開關講的是「**某個功能開還是關**」，而單字本那排是**多選清單**——你在勾「哪幾本要進複習範圍」，勾選框才是對的形狀。iOS 系統設定裡也是這樣分的。

### 動畫要有，但要短

滑塊左右移動與軌道變色，`transition` 150ms 上下。沒有動畫的膠囊看起來像壞掉；動畫太長按起來會覺得遲鈍。

### 尊重「減少動態」

`@media (prefers-reduced-motion: reduce)` 時把 `transition` 關掉。使用者開了那個設定就是不想看到東西滑來滑去，這是一行的事。

## 這張票不做的事

- 不改任何行為——按下去發生什麼事完全不變
- 不動單字本那排的勾選框，也不動卡片列表的單字本篩選器
- 不引入任何 CSS 框架或元件庫
- 不改 `daily-reminder.ts` 一個字（這是純畫面的票）

## 這張票要怎麼決定長什麼樣

**別用文字描述比稿。** 膠囊的圓角、軌道高度、滑塊留白、關閉時的灰階——這幾個數字寫在票裡看不出差別，並排看實物三秒就決定了。

動工時先用 `/prototype` 做一頁靜態 HTML，把兩三種尺寸與配色並排放在現有的深色背景上，維護者挑完再寫進 `styles.css`。原型是丟掉的，不進版控。

## 驗收

- [ ] 提醒那顆開關是膠囊式，開／關兩態一眼分得出來
- [ ] 點膠囊本體、點旁邊那行字，兩處都能切換
- [ ] 切換時有短動畫，不是瞬間跳過去
- [ ] 開啟「減少動態」之後沒有動畫，但仍然切換得動
- [ ] 用鍵盤 Tab 走得到，空白鍵切換得動，focus 看得出來在哪
- [ ] 觸控目標不小於現有的 `--tap`，在 iPhone 上不必瞄準
- [ ] 淺色與深色兩種系統外觀下都看得清楚
- [ ] 單字本那排的勾選框外觀零變化
- [ ] 按下去的行為與票 09 完全相同（權限請求、被拒絕時彈回去、關掉時清空提醒）
- [ ] 網頁版零變化——那裡本來就不出現這一區
- [ ] 既有測試全數通過
