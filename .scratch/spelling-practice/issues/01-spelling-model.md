# 拼字的出題、作答與計分，收成一支不碰畫面的模組

Status: ready-for-agent
Type: enhancement

## 問題

拼字要決定的事有一半跟畫面無關：這一輪出哪幾張卡、正解是哪幾個假名、點下去補到哪一格、取消哪一格、拼完算不算對、拿幾分、一輪結束時的成績長什麼樣。

這些全部塞進畫面裡的話就只能靠點擊來測。`core/lib/review.ts` 已經立了規矩：排程與抖動收在純函式裡，時間與亂數一律以參數注入，模組內不取用系統時鐘或全域亂數。這張票照同一套做。

## 用詞

`CONTEXT.md` 的新條目：**拼字**、**磚**、**一輪**、**計分**。整張票只用這四個詞，不要飄到「題目」「選項」「分數」「關卡」。

**磚**是單個假名，不是整串讀音——這是 A 案跟被否決的四選一之間最根本的差別。

## 決定

1. **新開 `core/lib/spelling.ts`**，不塞進 `review.ts`。那支管的是排程，這支一行排程都不碰（`ADR-0021`），混在一起會讓「拼字不寫 `due`」這條規則失去一道天然的界線。

2. **正解取自 `toReadingText()`**（`core/lib/reading.ts`），把詞條的漢字換成標注的讀音。`焦[こ]がす` → `こがす`。純假名詞條原樣就是正解。

3. **出題資格：正解必須整串都是假名。** 有漢字卻沒標讀音的卡，`toReadingText()` 會把漢字原樣吐回來，那種卡濾掉不出題（spec 決定 16）。判準與 `reading.ts` 的 `KANA` 同一條正則，不要另寫一條。

4. **時限 = 正解假名數 × `SECONDS_PER_KANA`**，常數初值 `3`。

5. **計分** 照 spec 決定 8：

   ```ts
   /** 時限的前三成之內拼完給滿分，之後線性遞減到 1 分。拼錯與逾時 0 分。 */
   export function points(elapsed: number, limit: number): number
   ```

   `FULL_POINTS_RATIO` 初值 `0.3`、`MAX_POINTS` 初值 `10`，都是具名常數。邊界要有測試：`elapsed = 0.3 × limit` 剛好 10 分，`elapsed = limit` 剛好 1 分。

   **不叫 `score`**：`Score` 是「評分」（複習的四級自評）的避用詞，`docs/glossary.md` 把它一併列為「計分」的避用詞。這張票原本寫成 `score()`，與同一次談話定下的那條避用詞打架，實作時改掉了。

6. **一輪的狀態機**：持有洗好的卡序、目前這一題、每一格填了哪一塊磚。對外至少要有

   - `startRound(cards, random)` — 濾掉沒資格的卡、洗牌，回傳一輪
   - `place(round, tileIndex)` — 把那塊磚放進**最前面的空格**；沒有空格就原樣回傳
   - `clearSlot(round, slotIndex)` — 只清那一格，其他格不動，那塊磚回到可點的狀態
   - `settle(round, elapsed)` — 整排填滿或逾時之後判定，回傳這一題的分數與對錯，並推進到下一題
   - `summary(round)` — 一輪的成績

   全部是純函式，回傳新的一輪，不就地改。與 `review.ts` 的 `rate()` 同一種形狀。

7. **整排填滿之前不判對錯**（spec 決定 3）。`place()` 只負責放，不回答對錯；判定只發生在 `settle()`。這一條要有測試釘住：連放三塊錯的磚，中途每一步都不得吐出「錯」。

8. **亂數注入，不用 `Math.random()`。** 洗牌與干擾挑選都吃傳進來的 `random: () => number`，照 `buildQueue()`（`core/lib/review.ts`）的簽名。

9. **時間也注入。** 這支模組不看時鐘：`settle()` 吃的是「花了幾秒」這個數字，由畫面那層量。碼表怎麼跑是畫面的事。

10. **成績要帶得出逐格對照要用的東西**：每一張沒拼對的卡，要有釋義、正解的每一格、以及使用者當時填的每一格（逾時沒填完的格子是空的）。票 `05` 直接畫它，不再自己重算。

11. **平均分 = 總分 ÷ 全部題數**，不是除以拼對的題數（spec 決定 23）。

12. **不碰排程、不碰儲存。** 這支模組不 import `storage.ts`，也不回傳任何要寫進 `AppData` 的東西。

13. **逾時一律不算拼對**，即使倒數歸零的那一瞬間剛好把最後一塊磚放對也一樣。實作時才發現的邊界：只比對格子內容的話，那一題會拿到「拼對＋0 分」，成績頁的「拼對 9 / 12」就會混進一題一分都沒拿的。維護者選定「時間到了就是沒過關」。剛好壓在時限上（`elapsed === limit`）仍算拼對，拿 1 分。

## 驗收

- `core/lib/spelling.ts` 存在，沒有 import `storage.ts`，也沒有呼叫 `rate()`。
- 沒有 `Math.random()`、沒有 `Date.now()`、沒有 `new Date()`。
- `焦[こ]がす` 的正解是 `こがす`；純假名詞條 `くしゃみ` 的正解是它自己。
- 有漢字卻沒標讀音的卡（`text` 是 `焦がす`）被濾掉，不出現在一輪裡。
- 三個假名的題目時限 9 秒，六個假名 18 秒。
- 計分邊界：`elapsed` 等於時限的三成時剛好 10 分，等於時限時剛好 1 分，拼錯與逾時 0 分。
- 連續放三塊錯磚，前兩步都不判對錯，第三步（整排滿）才判錯。
- 清掉中間那一格之後，前後兩格的內容不變；下一次 `place()` 補進的是被清掉的那一格。
- 同一組 `random` 種子跑兩次，卡序完全一樣。
- 一輪裡每張卡剛好出現一次，出完就結束。
- `summary()` 吐得出總分、拼對題數、總題數、平均分，以及每張沒拼對的卡的釋義、逐格正解、逐格作答。
- `core/lib/spelling.test.ts` 涵蓋上述每一條。
- 根目錄 `npm test` 與 `npx tsc --noEmit` 全過。
