# 拼字的字全部進翻譯檔，三份都要

Status: ready-for-agent
Type: enhancement

## 問題

`ADR-0013` 定的：畫面上的字一律查表，三種語言（繁中／英／日）各一份。拼字整套是新畫面，字全是新的——導覽鈕、挑書頁、題目提示、成績頁的三個標籤、兩顆按鈕、空畫面的說明。

`en.ts` 與 `ja.ts` 是 `const en: typeof zhHant`，少一條就編譯錯，所以「漏翻」這件事型別會擋。**擋不住的是翻錯**，那要人看。

## 用詞

譯名的正本是 `docs/glossary.md`。這次新增的四則是**拼字 / Spelling / スペル**、**磚 / Tile / 仮名タイル**、**一輪 / Round / ラウンド**、**計分 / Points / ポイント**。

**「計分」的英文不能用 `Score`。** 那是「評分」（複習的四級自評）的避用詞，兩邊都用會把兩件事攪在一起。

## 決定

1. **新開 `spelling.*` 分區**，比照現有慣例（`nav.*` 是共用的導覽字，其餘各自對應一支檔案）。

2. **`nav.spelling` 加進 `nav.*` 分區**，並把 `zh-Hant.ts` 開頭那句「`nav.*` 是**四個**畫面共用的導覽字」改成五個。

3. **key 用語意命名，不用中文原文**，沿用既有規矩（`books.addButton` 那種）。

4. **帶數字的字串走參數，不要字串拼接**：成績頁的「9 / 12」、剩餘秒數、題數，都用 `t()` 的參數佔位符。中文與日文的數字位置跟英文不一樣，拼接會在某一種語言下讀不通。

5. **`src/i18n/smoke.test.ts` 那條「五個主要畫面都畫得出來」要把拼字加進去。** 拼字有三個畫面狀態（挑書、答題、成績），三個都要進那支冒煙測試——它抓的是「畫面上有沒有漏掉沒查表的原始 key」，漏一個狀態就等於漏一整頁。

6. **「拼字」的日文是 `スペル`，維護者選定。** 中文的「拼字」、英文的 `Spelling`、日文的 `スペル` 是同一個概念的三種寫法，三邊一致。

   另外三則的日文（`仮名タイル`、`ラウンド`、`ポイント`）是提案，端給維護者時他沒有表示異議，但也沒逐條確認過。都是直白的外來語，動它們的門檻很低。

## 驗收

- 拼字的三個畫面狀態上，一個中文字都沒有寫死在 `.ts` 裡。
- `en.ts` 與 `ja.ts` 都補齊，`npx tsc --noEmit` 過（少一條會編譯錯）。
- 切到英文，拼字三個畫面沒有中文殘留；切到日文同理。
- 成績頁的「9 / 12」在三種語言下都讀得通，不是字串拼接出來的。
- `zh-Hant.ts` 開頭「四個畫面共用的導覽字」已改成五個。
- `src/i18n/smoke.test.ts` 涵蓋拼字的挑書、答題、成績三個狀態，畫面上抓不到任何原始 key。
- 導覽鈕上的字是「拼字」，不是「練習」。
- 「計分」的英文不是 `Score`。
- 日文的導覽鈕是「スペル」。
- 根目錄 `npm test` 與 `npx tsc --noEmit` 全過。

## Comments

票 `05` 實作時已經照票 `04` 的先例，把成績頁與「結束」用到的字三份都補上了：`spelling.quit`、`spelling.correctRatio`、`spelling.correctLabel`、`spelling.pointsLabel`、`spelling.averageLabel`、`spelling.yourTry`、`spelling.answer`、`spelling.noMistakes`、`spelling.again`、`spelling.otherBooks`。這張票對它們的工作是**看翻得對不對**，不是重加一次。

三則已經照決定做掉的：「9 / 12」走的是 `spelling.correctRatio` 的兩個參數，不是字串拼接；`spelling.pointsLabel` 的英文是 `Points` 不是 `Score`；日文的頂上那一格是 `正解数`，逐格對照那一行是 `正解`——同一個畫面上兩個都在，刻意分成兩個詞。

還沒做的仍然是決定 2（`nav.spelling` 與 `zh-Hant.ts` 開頭那句「四個畫面」改五個）與決定 5（冒煙測試加拼字三個狀態）。後者要等票 `06` 把入口接上，那支測試是從 `start()` 開機照使用者的走法按過去的，按不到「拼字」就走不進拼字。
