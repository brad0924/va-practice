# 干擾磚不要出現 ゐ ゑ：廢棄假名混進了五十音表

Status: ready-for-agent
Type: bug

## 問題

拼字的干擾磚會擺出 `ゑ`。那是**廢棄的歷史假名**，現代日文一百年前就不用了，JLPT 一輩子不會考。使用者沒見過它，看到的時候會以為是畫面壞了——2026-09-08 跑票 `05` 的驗收時，維護者截圖回報「`る` 這個音的顯示好像怪怪的」，實際看到的字是 `ゑ`。

成因在 `core/lib/spelling.ts` 的 `buildRows()`：那張表不是手打的，是**照 Unicode 平假名區一個碼位一個碼位數出來的**（票 `02` 決定 2 刻意要求的，手打會漏會錯）。而 わ 行在那條線上長這樣：

```
ゎ(U+308E) わ(U+308F) ゐ(U+3090) ゑ(U+3091) を(U+3092)
```

`ゐ` 與 `ゑ` 就住在 `わ` 跟 `を` 中間，數過去時自然被數進來。片假名那邊同理：`toKatakana()` 是固定加 `0x60`，因此 `ゐ`／`ゑ` 會變成 `ヰ`／`ヱ`。

**命中率不低。** `variantsOf('わ')` 會把同一行沒帶濁點的鄰居全部拉出來當候選，也就是 `ゎ`、`ゐ`、`ゑ`、`を` 四個；只要那個詞裡有 `わ`（`でんわ`、`かわいい`、`わたし`⋯⋯），`ゐ` 與 `ゑ` 就排在最前面的候選裡。短詞另有一條路：候選不夠時 `wholeTable()` 會從整張表補，同樣補得到它們。

## 用詞

**磚**、**干擾**照 `CONTEXT.md` 與票 `02`。這張票不碰計分、不碰畫面。

## 決定

1. **把 `ゐ`、`ゑ`、`ヰ`、`ヱ` 從干擾用的五十音表裡拿掉。** 表的成員從 83 個變成 81 個。

2. **只拿掉這四個。** 維護者看過三種範圍之後選的：

   - `ゎ`／`ヮ`（小寫的 wa）**留著**。大小寫混淆本來就是這個玩法要練的東西（票 `02` 決定 1 的同一個立場，`くしゃみ` 的 `ゃ` 要有 `や` 陪它），雖然 `ゎ` 現代日文幾乎不出現，它至少是使用者認得的形狀。
   - `を`／`ヲ` **留著**。它只當助詞、不會出現在單字的讀音裡，因此當干擾很容易被排除、幾乎沒有難度；但使用者認得它，不會看成亂碼。這張票要解的是「看起來像畫面壞了」，不是「干擾夠不夠難」。

3. **改在 `buildRows()` 這一個地方。** 那是整支唯一建表的函式，三個吃表的地方（`variantsOf()` 的同行鄰居、`adjacentRows()`、`wholeTable()`）都讀它，改一處三條路一起乾淨。**不要**在 `decoysFor()` 出口再濾一次——那等於把同一條規則放兩份。

4. **`ROW_ENDS` 那一行不動。** 它是行的邊界，`を` 仍然是 わ 行的最後一個字；排除是在數完之後做的，行的切法不受影響。docblock 裡「每一行佔 10、10、10、11、5、15、5、6、5、5、1 個位置」那段要跟著更新成排除後的數字。

5. **出題資格不受影響。** 讀音真的含 `ゐ` 的卡（舊文獻、人名）照樣出得了題：正解走的是 `toReadingText()` 與 `reading.ts` 的 `KANA` 正則，跟這張表無關。表只決定干擾。

6. **磚數不變。** 仍然是「正解假名數 ＋ `DECOY_COUNT`」（票 `02` 決定 3）。わ 行少了兩個候選之後，`decoysFor()` 現有的兩層備案（先補相鄰行、再補整張表）本來就補得滿，不必調 `DECOY_COUNT`。

## 驗收

- 讀音含 `わ` 的詞（例如 `でんわ`）出的題，磚上一塊 `ゐ`、一塊 `ゑ` 都沒有。
- 讀音含片假名 `ワ` 的詞出的題，磚上沒有 `ヰ`、`ヱ`。
- 兩個假名的短詞（會走到「從整張表補」那條備案）出的題，磚上也沒有那四個字。
- 含 `わ` 的詞，磚數仍然是正解假名數加 6，一塊都沒少。
- `ゎ` 與 `を` 仍然拉得出來當干擾——這張票沒有把它們一起拿掉。
- 讀音是 `ゐ` 的卡照樣出得了題，正解格顯示 `ゐ`。
- `core/lib/spelling.test.ts` 有一條直接釘住「表裡沒有這四個字」，另有一條釘住 `でんわ` 那種詞的磚不含它們。
- 根目錄 `npm test` 與 `npx tsc --noEmit` 全過。

## Comments

回報路徑值得記一下：這個 bug 是**票 `05` 的手動驗收撞出來的**，不是測試抓到的。`spelling.test.ts` 驗的是「干擾不與正解重複」「不彼此重複」「磚數固定」這類結構性質，而 `ゑ` 完全符合那幾條——它是一個合法的、不重複的假名。「這個字使用者認不認得」不是結構性質，只有人看得出來。

同一次驗收還撞出另一件事（成績頁的 `.missed` 與答題畫面的 `.slot.done.missed` CSS 撞名），記在票 `05` 的 Comments。兩件都是自動測試蓋不到、要眼睛看的那一類。
