# docs/spec.md 補上到期排序的方向切換

Status: ready-for-agent
Type: bug

## 需求

issue 01 把新卡從「墊底」改成「視為最早到期」，並加了一顆「到期 ↑／↓」切換鈕。`docs/spec.md` 三處沒跟上，其中一處與測試現況完全相反。

| 行 | 現在寫的 | 實際 |
|---|---|---|
| 129 | 「新卡墊底」「排序固定、不提供切換」 | 新卡排最前；有切換鈕 |
| 176 | 測試驗證「新卡**永遠墊底**」 | `src/lib/review.test.ts:213`、`:260` 明寫「排最前」，另有 `:232`、`:272` 兩條倒序案例 |
| 207 | Out of Scope 寫「不提供切換」 | 一半假：方向切換已經有了；還沒有的是「切回原始順序／改以其他欄位排序」 |

第 176 行最急——它會讓下一個讀 spec 的人以為測試在守一件與事實相反的事。三行都不影響程式行為。

`CONTEXT.md:91` 的〈到期排序〉詞條寫的才是正確現況，可直接當改寫範本。

## 決定

1. **只改敘述，不動程式。** 這張票是文件對齊，`src/` 底下一個字都不碰。

2. **第 129 行**改寫成：正序為「新卡 → 逾期最久 → 逾期較短 → 今日到期 → 未來（越遠越後）」，倒序整個反過來、新卡沉到最底；到期日相同者維持資料中的原始順序；預設為正序，畫面上有一顆切換方向的按鈕，搜尋結果亦套用同一規則。

3. **第 176 行**把「新卡永遠墊底」改成「新卡在正序時排最前、倒序時沉到最底」，並補上倒序也在測試涵蓋範圍內。

4. **第 207 行**縮小到真正還在範圍外的部分：方向切換已提供；不做的是切回原始順序、以及改以其他欄位排序。
