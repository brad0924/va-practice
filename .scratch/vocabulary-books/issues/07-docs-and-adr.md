# 文件收尾：CONTEXT.md 詞彙、docs/spec.md 更新、兩則 ADR

Status: done
Type: enhancement

決策背景見 `.scratch/vocabulary-books/spec.md`。依賴 `01`–`06` 全部完成。

## 需求

把單字本的詞彙寫進 `CONTEXT.md`、拿掉已消失的概念、更新 `docs/spec.md` 裡與本次相衝的段落，並替兩個難以回頭的決定各留一則 ADR。

## 決定

### CONTEXT.md

1. **新增詞條**（維持既有格式：定義一段白話、外加 `_Avoid_:` 一行）：

   - **單字本（Vocabulary Book）**：卡片的容器。一張卡剛好屬於一本，不能同時屬於多本，也不能無家可歸。名字由使用者自取、可隨時改；刪掉一本，裡面的卡與進度一併消失。
     `_Avoid_`: 牌組（本專案裡專指已退場的內建牌組）、分類、標籤、資料夾
   - **詞條全域唯一**：同一個詞條在整個 app 裡只會有一張卡，跨單字本亦然。想讓另一本擁有某個詞，只能把那張卡搬過去。比對基準是去掉讀音標記後的詞條原文，釋義不參與。
     `_Avoid_`: 去重、防呆、唯一鍵
   - **複習範圍／列表範圍／統計範圍**：三個畫面各自獨立的單字本選擇。三組都是複選、都至少要有一本、都隨資料備份到雲端。改其中一組不影響另外兩組。
     `_Avoid_`: 篩選器（會讓人以為只是暫時的視圖）、模式、書籤
   - **匯入單字**：把一份備份檔裡的卡加進指定的一本，複習進度原封搬過來，已存在的詞跳過並在結束時一次列出。與「備份」的整份覆蓋是兩件事。
     `_Avoid_`: 匯入（會與備份的匯入混淆）、同步、合併

2. **刪除詞條**：「內建牌組」「單向合併」——兩者已不存在。

3. **修改詞條**：「備份」與「雲端備份」的說明需涵蓋單字本與三組範圍選擇一併被覆蓋這件事。

4. `CONTEXT.md` 是詞彙表，不是規格書——不要把實作細節（欄位名、正規化步驟、UI 位置）寫進去。

### docs/spec.md

5. **Out of Scope 移除「多牌組：僅支援單一牌組」**，該項已被本次推翻。

6. **「模組與接縫」一節**：資料存取模組的職責描述需更新——移除單向合併，加入單字本的維護、名稱與詞條約束、匯入單字、範圍過濾。接縫數量不變（未新增接縫）。

7. **「資料模型」一節**：反映 `books`、`bookId`、`scopes` 與版本 3，移除 `knownBuiltinIds`。

8. **「Testing Decisions」一節**：資料存取那一條的內容需更新（單向合併的測試已移除，新增單字本相關情境）。

9. **「資料來源與已知修正」等提到內建牌組／AnkiApp 匯出的段落**：改寫為歷史說明，明確指出該來源已退場。

### ADR

10. **新增 ADR：詞條全域唯一。** 三個條件都成立——難以回頭（放寬成「本內唯一」之後已建立的資料無法反推）、沒有脈絡會讓人困惑（為什麼不能在兩本裡各放一張）、是真的取捨（同一天被問兩次 vs 無法在不同脈絡下各練一次）。需記下被否決的兩案（一卡多本的標籤模型、兩本各一張獨立的卡）與否決理由。

11. **新增 ADR：內建牌組退場。** 同樣三個條件成立——刪掉 `cards.json` 與單向合併之後，要回頭得重建整套機制；未來讀 code 的人會問「這個 app 為什麼開箱是空的」；取捨是「新裝置開箱即用」換掉「模型乾淨、發佈不再偷改使用者資料」。需記下被否決的兩案（保留為可選匯入、維持自動塞入）。

12. **不為以下事項開 ADR**：三組範圍分開控制、資料頁的版面、匯入時跳過重複——這些改起來成本低，屬於一般設計決定，spec 已記錄。

13. ADR 編號接續現有的 `docs/adr/0006-*`，格式沿用既有檔案。

## 驗收

- `CONTEXT.md` 不再出現「內建牌組」與「單向合併」，且新增的四個詞條格式與既有詞條一致。
- `CONTEXT.md` 全篇不含欄位名、函式名、檔案路徑等實作細節。
- `docs/spec.md` 的 Out of Scope 不再宣稱僅支援單一牌組。
- `docs/spec.md` 描述的接縫數量與實際程式碼一致。
- 兩則新 ADR 各自寫清楚背景、決定、被否決的替代方案與後果。
- 全篇文件中提到的檔案與函式確實存在（不留指向已刪除 `src/data/cards.json` 的敘述）。

## Comments

1. **`docs/spec.md` 全篇改乾淨**，不限於本票點名的五處。Problem Statement、Solution、User Stories 34／37／38、〈排程〉的「132 張全數進入佇列」、〈讀音標記〉、〈預期的使用曲線〉原本都還在描述內建牌組的世界，一併改寫。連帶調整：User Story 新增第 39 條（詞條全域唯一），其後的〈裝置與部署〉由 39–44 順移為 40–45；Out of Scope 補上單字本相關的五條並把「原牌組的附件」併入歷史說明那一節；〈卡片列表〉補上單字本篩選與列上本名。`CLAUDE.md` 開頭那句「資料來源是 AnkiApp 匯出的 JLPT N2 牌組」同樣已不成立，一併改掉。
