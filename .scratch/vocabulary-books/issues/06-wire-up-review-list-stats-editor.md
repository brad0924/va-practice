# 把單字本接上複習、卡片列表、統計與編輯器

Status: ready-for-agent
Type: enhancement

決策背景見 `.scratch/vocabulary-books/spec.md`。依賴 `01`、`03`、`05`。本票只做畫面與接線。

## 需求

複習依複習範圍出題；卡片列表與統計各有自己的一組範圍開關；編輯器多一個「單字本」下拉。

## 決定

### 複習

1. **複習畫面不放任何單字本開關**，頂部列維持「剩餘 N 張」與「卡片」。範圍在資料頁設（見票 05）。

2. **佇列改吃過濾後的卡片**：`buildQueue(cardsInBooks(cards, scopes.review), now, random)`。`buildQueue()` 本身不動，洗牌邏輯不動——多本的卡自然交錯出現，不做同本連續出題。

3. **從資料頁回到複習畫面時重建佇列**，讓範圍的改動立即生效。

4. **新增一張卡時，只有它屬於複習範圍內的本才加入當日佇列**（現行 `upsert()` 無條件加入，需加上這個判斷）。

### 卡片列表

5. **上方一組單字本篩選**，獨立於複習範圍。位置在既有搜尋框附近，與「共 N 張／到期 ↑」那條工具列並存。

6. **每一列右邊顯示該卡所屬的本名。** 只顯示，不可點——列上不做搬家（點該列仍是進編輯器）。既有的到期日欄位保留。

7. **篩選發生在搜尋與分桶之前**：`groupByBucket(filter(cardsInBooks(cards, scopes.list), query), now, direction)`。`groupByBucket()` 與 `filter()` 皆不動。

8. **張數的文案跟著範圍走**：「共 N 張」的 N 是範圍內的張數，不是全 app 的張數。

### 統計

9. **一組單字本範圍**，獨立於前兩者。

10. **`computeSnapshot()` 不動**，傳過濾後的卡片進去即可：`computeSnapshot(cardsInBooks(cards, scopes.stats), now)`。

11. **不做「每本一列」的比較表。** 想看單一本切過去即可。

### 三組開關共通

12. **三組長得一樣**：複選、下拉最上面一個「全部」項目（點它＝全部勾起來）、至少一本。全部勾滿時收合後的標籤顯示「全部」，否則顯示本名或本數。

13. **只剩一本單字本時，那本不可取消勾選**（disabled）。

14. **零本時**三個畫面各自顯示自己的空狀態，開關不顯示。

### 編輯器

15. **新增一個「單字本」下拉**，放在詞條之前。

16. **新增卡片時預設「這次開 app 期間上一張卡選的那本」**，第一次進來則是清單第一本。此偏好只活在記憶體，不進 `storage`，也不進備份。

17. **編輯既有卡時改掉下拉就等於搬家**，`interval`／`ease`／`due` 不變。

18. **詞條撞到別本已有的詞時，在儲存時擋下**，訊息要說出它現在在哪一本。與既有的「詞條與釋義必填」同一個時機、同一種呈現。

19. **零本時不能新增卡片**——「新增」入口應導向「先建一本單字本」，而不是開出一個沒有單字本可選的編輯器。

## 驗收

手動驗收（依 `docs/spec.md`，畫面不寫自動化測試）；`npm test` 須維持全綠，`groupByBucket` 與 `computeSnapshot` 的既有測試一字未改。

- 取消某本的複習勾選（資料頁）→ 回複習畫面，該本的卡不出現在佇列；卡片列表與統計的顯示不受影響。
- 卡片列表切成只看某一本 → 只剩那本的卡，「共 N 張」跟著變；複習佇列不受影響。
- 統計切成只看某一本 → 總數、已複習張數、平均間隔、時間桶與熟練度分佈都只算那本；另外兩個畫面不受影響。
- 卡片列表每一列右邊看得到本名，點該列仍然進編輯器。
- 三組開關各自有「全部」項目，點它變成全選；標籤在全選時顯示「全部」。
- 只剩一本時三組的勾選都點不動。
- 編輯器新增卡：下拉預設是上一張選的那本；換一本存檔後，那張卡出現在新的本裡且進度不變。
- 編輯器輸入一個別本已有的詞 → 儲存被擋，訊息說得出它在哪一本。
- 零本時按「新增」→ 被導去建立單字本，不會開出空下拉的編輯器。
- 在複習範圍內的本新增一張卡 → 立即進入當日佇列；在範圍外的本新增 → 不進佇列。
