# 資料頁的「單字本」區：清單、複習範圍勾選、改名／匯入／刪除

Status: ready-for-agent
Type: enhancement

決策背景見 `.scratch/vocabulary-books/spec.md`。依賴 `01`、`03`、`04`。本票只做畫面。

## 需求

資料頁長出「單字本」區，是新增／改名／刪除單字本、匯入單字、以及設定**複習範圍**的唯一地方。

## 決定

1. **放在資料頁最上面**，在既有的雲端備份、Gemini 金鑰、備份檔案三區之前。

2. **整區可收縮，預設展開。** 放到最上面就是因為它是主角，一進去還收著等於白放。（卡片列表的時間桶預設收合是另一回事，那裡一次要塞一百多列。）

3. **一本一列**：勾選框 ＋ 本名 ＋ 張數。勾選框的意義是「**納入複習範圍**」——這是複習範圍唯一的設定入口，複習畫面上不放任何開關。

4. **點該列展開，才出現「改名」「匯入」「刪除」三顆。** 平常看到的就是「哪幾本要練」這件事，不常用的維護鈕收起來。同時只展開一列。

   ```
   單字本                    ▾
   ───────────────────────────
    ☑ JLPT N2         132 張
    ☑ 工作用日文        30 張
      └─ [改名] [匯入] [刪除]
    ☑ 文法句型          18 張

    [+ 新增單字本]
   ```

5. **只剩一本時，那本的勾選框 disabled**，避免違反「至少一本」。

6. **零本時**顯示「還沒有單字本」與「新增單字本」入口，不顯示空的清單。

7. **新增與改名用同一組輸入介面。** 名稱違規（空白、重名）時在按下確定後顯示原因，不做邊打字邊提示——沿用編輯器現有「詞條與釋義沒填就存不下去」的做法。

8. **刪除前跳確認**，訊息必須說出張數與不可復原：形如「將一併刪除 30 張卡片與它們的複習進度，無法復原。」沿用資料頁現有 `confirm()` 的做法（見 `STOP_CONFIRM`）。

9. **匯入單字**沿用備份檔那一區既有的選檔做法。結束後**一次列出所有被跳過的詞**，每一筆標明它目前在哪一本；匯入張數也要顯示。清單可能很長，需可捲動，且不會被壓出容器外（見 `.scratch/stats-snapshot` 的同類修正）。

   ```
   已匯入 159 張

   以下 3 個詞已存在，已跳過：
    ・打ち合わせ（JLPT N2）
    ・焚がす（JLPT N2）
    ・約束（JLPT N2）
   ```

10. **複習範圍改動後回到複習畫面時重建佇列。** 資料頁本身不需要立即重建。

11. 中文文案與樣式一律留在畫面這一側；所有判斷（名稱是否合法、範圍是否會被清空、匯入結果）都來自資料存取模組。

## 驗收

手動驗收（依 `docs/spec.md`，畫面不寫自動化測試）：

- 資料頁最上面就是「單字本」區，預設展開，可收起來再打開。
- 新增一本 → 出現在清單末端、勾選框已勾、張數為 0；回到複習畫面，該本的卡（若有）會進佇列。
- 取名為空白 → 被擋並看得到原因；取名為既有本的另一種大小寫／全形寫法 → 被擋。
- 改名 → 清單上的名字變了，該本張數不變，卡片列表上該本的卡仍在。
- 點一列 → 出現三顆鈕；點另一列 → 前一列收起來。
- 刪除 → 跳出含張數的確認；取消則什麼都沒發生；確認則該本與它的卡一起消失，且從三組範圍移除。
- 只剩一本時，那本的勾選框點不動。
- 全部刪光 → 顯示「還沒有單字本」與新增入口。
- 匯入一份含重複詞的備份檔 → 看到匯入張數與完整的跳過清單，清單長時可捲動、不被切掉。
- 取消某本的勾選 → 回到複習畫面，該本的卡不再出現在佇列；卡片列表與統計不受影響。
