# 04: 進問答先挑單字本，選擇記在這台裝置、與拼字分開

Status: done
Type: enhancement
Blocked by: 02

## 要做什麼

使用者點「問答」進來，先挑這一輪要練哪幾本，下次進來記得上次挑的。拼字挑的與問答挑的互不影響，手機挑的與電腦挑的也可以不一樣。

**先做一個小整理（prefactor），再往上蓋。** 拼字已經有一支「記住挑了哪幾本」的本機存放，問答要的行為一模一樣，只是存在另一格。先讓那支存放把「存在哪一格」當成參數收進來，拼字傳它現在那一格，確認拼字的測試全綠，再讓問答傳自己新開的一格。**拼字那一格的名字一個字都不能改**，否則使用者已經存著的選擇會全部消失。

用詞：不要叫「問答範圍」，「範圍」專指那三組跟著備份走的選擇。畫面上的字用「單字本」。

票 03 也會動成績頁。兩張誰先做都行，後做的那張順手合一下。

## 驗收

**預先整理**
- [x] 存放收「存在哪一格」當參數；拼字那一格的名字與行為完全沒變，拼字原有的測試不改一行照樣綠。

**挑書**
- [x] 進場規則改成：上一輪還封存著就給成績頁，否則給挑書頁（票 02 的「直接用全部單字本開一輪」拿掉）。
- [x] 挑書頁比照拼字那一頁：用現成的單字本選單，至少要挑一本才能開始。
- [x] 問答挑的那幾本存在本機自己那一格，不進 `AppData`、不進備份、不上雲端（`ADR-0021`）。
- [x] 在拼字挑了 N3，進問答看到的仍是問答自己上次挑的；反過來也一樣。
- [x] 存的那幾本被刪光（或存的那一格讀壞了），進來時全部單字本都勾起來，不當機、不出一輪空題。
- [x] 一本單字本都沒有時，比照拼字挑書頁的零本版本。
- [x] 挑到的本裡沒有可出的卡、或整個 app 湊不出四個不同的釋義時，給與拼字「這本是空的」同一個空畫面。（票 06 之後改了前提，做法見收工紀錄）

**成績頁**
- [x] 成績頁多一顆「換單字本」，回挑書頁；回到挑書頁即放掉上一輪。
- [x] 「再一輪」與挑書頁走同一段開一輪的程式，用同一批單字本重來。

**三語與測試**
- [x] 新增的畫面文字三份翻譯檔都補齊，動手前先讀翻譯檔開頭的規矩。
- [x] 本機存放的測試：拼字那一格與問答那一格互不影響（node 環境，前例是拼字那支存放的測試）。
- [x] 冒煙測試走進問答的挑書頁，三種語言各一次。

## 規格出處

`.scratch/quiz/spec.md` 實作決定五、六；測試決定「接縫二」。

## 收工紀錄

票 03 先做完了，成績頁這張是後做的：「換單字本」加在「再一輪」旁邊，排法照抄拼字成績頁。

**預先整理。** `core/lib/spelling-books.ts` 多一支 `createBookPicks(storage, key)`，拼字那支 `createSpellingBooks(storage)` 留成一行，內容是帶入原本那一格去呼叫它。拼字那一格 `va-practice:spelling-books` 沒動；問答新開 `va-practice:quiz-books`（`QUIZ_BOOKS_KEY`）。拼字原有的存放測試一行沒改，新的幾條接在檔尾，import 另起一行。

**挑書頁不開一輪，這是與拼字唯一的差別。** `src/ui/quiz-books.ts` 只管勾選、存回本機、印那一句紅字，按「開始」把挑到的那幾本交出去。開一輪（含等 Gemini）住在 `quiz-home.ts` 的 `roundPage()`，挑書頁的「開始」與成績頁的「再一輪」都走它。

維護者拍板的一件事：

- **出不了題時人留在挑書頁，勾選框底下印一句紅字**，比照拼字。這張票寫於票 06 之前，當時只有「這本是空的」一種原因；票 06 之後有三種（挑到的本沒有寫了釋義的卡、沒設金鑰、Gemini 沒補成），三種各印自己那一句。要等 Gemini 時照舊先跳「正在準備」那一頁，補不成才退回挑書頁印那一句。票 02 那張整頁說明（`quiz.noCardsTitle`）因此拿掉。

實作時自己拍板的事：

- **`quiz.noCardsNote` 改寫**成「挑到的單字本出不了題：裡面沒有寫了釋義的卡。換幾本，或多加幾張卡再開始」，因為它現在印在挑書頁上。英文那句避開 `questions`（卡片的避用詞）。
- **挑書頁那一句提示多講一句「與拼字挑的分開」**，不講的話兩邊不一樣會被當成壞掉。
- **干擾照樣從整個 app 抽**，只有出題的卡限挑到的那幾本（spec 實作決定三）。要不要請 Gemini 補，也照整個 app 算；送去補的只有挑到的那幾本裡的卡。
- **`spelling-home.test.ts` 那道守門的問答那一列加了 `quiz-books`**。那一道是兩條線共用的（票 02），拼字那一列沒碰。

審查時提到、沒改的：

- 「再一輪」重新讀本機存的那幾本，不沿用上一輪手上那一份。從沒改過勾選的人（那一格沒寫過）在成績頁期間新建一本單字本，下一輪會把它算進去。拼字 `spelling-home.ts` 的 `again()` 同一種寫法，兩邊一致。
- 英文舊的 `spelling.noCards` 寫著 `cannot make any questions`，碰到 `Question` 這個避用詞。不在這張票的範圍。
