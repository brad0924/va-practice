# 04: 進問答先挑單字本，選擇記在這台裝置、與拼字分開

Status: ready-for-agent
Type: enhancement
Blocked by: 02

## 要做什麼

使用者點「問答」進來，先挑這一輪要練哪幾本，下次進來記得上次挑的。拼字挑的與問答挑的互不影響，手機挑的與電腦挑的也可以不一樣。

**先做一個小整理（prefactor），再往上蓋。** 拼字已經有一支「記住挑了哪幾本」的本機存放，問答要的行為一模一樣，只是存在另一格。先讓那支存放把「存在哪一格」當成參數收進來，拼字傳它現在那一格，確認拼字的測試全綠，再讓問答傳自己新開的一格。**拼字那一格的名字一個字都不能改**，否則使用者已經存著的選擇會全部消失。

用詞：不要叫「問答範圍」，「範圍」專指那三組跟著備份走的選擇。畫面上的字用「單字本」。

票 03 也會動成績頁。兩張誰先做都行，後做的那張順手合一下。

## 驗收

**預先整理**
- [ ] 存放收「存在哪一格」當參數；拼字那一格的名字與行為完全沒變，拼字原有的測試不改一行照樣綠。

**挑書**
- [ ] 進場規則改成：上一輪還封存著就給成績頁，否則給挑書頁（票 02 的「直接用全部單字本開一輪」拿掉）。
- [ ] 挑書頁比照拼字那一頁：用現成的單字本選單，至少要挑一本才能開始。
- [ ] 問答挑的那幾本存在本機自己那一格，不進 `AppData`、不進備份、不上雲端（`ADR-0021`）。
- [ ] 在拼字挑了 N3，進問答看到的仍是問答自己上次挑的；反過來也一樣。
- [ ] 存的那幾本被刪光（或存的那一格讀壞了），進來時全部單字本都勾起來，不當機、不出一輪空題。
- [ ] 一本單字本都沒有時，比照拼字挑書頁的零本版本。
- [ ] 挑到的本裡沒有可出的卡、或整個 app 湊不出四個不同的釋義時，給與拼字「這本是空的」同一個空畫面。

**成績頁**
- [ ] 成績頁多一顆「換單字本」，回挑書頁；回到挑書頁即放掉上一輪。
- [ ] 「再一輪」與挑書頁走同一段開一輪的程式，用同一批單字本重來。

**三語與測試**
- [ ] 新增的畫面文字三份翻譯檔都補齊，動手前先讀翻譯檔開頭的規矩。
- [ ] 本機存放的測試：拼字那一格與問答那一格互不影響（node 環境，前例是拼字那支存放的測試）。
- [ ] 冒煙測試走進問答的挑書頁，三種語言各一次。
