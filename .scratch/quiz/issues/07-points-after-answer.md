# 07: 答完那一刻印出這題拿幾分

Status: done
Type: enhancement
Blocked by: 02

## 為什麼有這張票

2026-09-18 維護者實機測完票 04 後問：「按下答案以後沒有像拼字一樣馬上看到分數，是正常的嗎？」

這是照規格做的。spec 實作決定七列了點下選項之後畫面要做的事（碼表停、選項鎖住、標讀音、正解綠、點錯紅、停 1 秒），清單裡沒有「印出這題幾分」。但規格談的時候沒有討論過這一點，比較像漏談，不是刻意不印。拼字答完會多一行「拼對了 · 8 分」，問答沒有，兩邊不一致。

當時端出三個做法：加一行分數、停留維持 1 秒；加一行分數、停留拉長到 1.6 秒；維持現狀。**維護者選了第一個。**

## 要做什麼

- **答完那一刻，畫面上多一行字**，講這一題的結果與分數。三種收尾各一句：答對、答錯、逾時。樣子比照拼字答題頁那一行（`spelling-view.ts` 的 `OUTCOMES` 與 `.verdict`）：字加顏色，答對綠、答錯紅、逾時用拼字那個「晚了」的顏色。
- **分數一律問 `settle()` 回傳的結果**，畫面自己不算。拼字那一行三句都吃 `{points}`，答錯與逾時必定是 0 分，但那條規則歸 `quiz.ts` 管，不寫死在句子裡。
- **過了時限才點下去，照逾時印**（票 02 已經把那種情況畫成逾時，這一行跟著走），不會出現「答對了 · 0 分」。
- **停留維持 1 秒**（`SETTLE_PAUSE_MS` 不動）。實玩之後嫌太趕再另外調。
- **這一行放在詞條底下**，也就是畫面上半、選項上面。選項在下半，點完眼睛本來就要往上看讀音，分數擺在同一塊。票 05 做左右兩欄時，這一行跟著詞條與碼表放左欄。
- **答題中、還沒點的時候，這一行是空的**，不佔位置也不閃。（「不佔位置」後來沒照做，見收工紀錄）

## 三語文字

問答自己一組 key（`quiz.settledCorrect`／`quiz.settledWrong`／`quiz.settledTimeout`），不借拼字那三條：拼字講的是「拼對」，問答是「答對」，與成績頁頂上那一格各自一組 key 同一個理由。

- 中文：`答對了 · {points} 分`、`答錯了 · {points} 分`、`逾時 · {points} 分`。逾時用「逾時」，不用拼字的「時間到」，與票 03 成績頁那兩個字一致。
- 英文與日文照拼字那三句的寫法（英文名詞在前 `Points: {points}`，日文 `{points}ポイント`）。動手前先讀每一份翻譯檔開頭的規矩。

## 收工紀錄

`src/ui/quiz-view.ts` 照抄拼字那一套：一張 `OUTCOMES` 表收三種收尾的 key 與顏色，詞條底下多一個 `.verdict`，樣式直接吃拼字那幾條（`.verdict`、`.ok`、`.bad`、`.late`），`styles.css` 沒動。

維護者拍板的一件事：

- **還沒點時那一行先佔住一行高度**，比照拼字 `.verdict` 的 `min-height`。上半那一塊是整組置中的，不佔位置的話，點下去那一刻詞條會往上跳約 18px，正好撞上讀音標上去的那一瞬間。代價是詞條從第一眼起就比票 04 時高一點。票上「不佔位置」那半句因此沒照做。

實作時自己拍板的事：

- **算哪一種收尾只看 `settle()` 回的那一份**（`outcomeOf()`）：`picked` 是 null 就是逾時。過了時限才點的那一下在 `pick()` 已經改成 null，這裡不必再看時間，也就不會印出「答對了 · 0 分」。
- **顏色沒有自動測試**，與拼字答題頁一致：字與顏色查同一張表，字對了顏色就不會挑錯。`outcomeOf()` 因此沒有匯出。
- **英文與日文三句與 `spelling.settled*` 同字**：`Correct`／`Wrong`／`Time's up` 與 `正解`／`不正解`／`時間切れ` 放在問答一樣講得通，也與 `quiz.timedOut` 的英日兩份同字。
- **冒煙測試不用改**：現有那一步在逾時與點選兩種情況的停留期間都查過一次，新的一行就在那時候出現。

審查時抓到、改了的：

- **點下選項時時鐘只讀一次。** 票 02 的 `pick()` 讀一次時鐘判斷算不算逾時，`finishQuestion()` 又讀一次交給 `settle()`。剛好卡在第 10 秒的那一下，兩次讀數會落在時限兩邊：前者說沒逾時、後者給 0 分，畫面印出綠的正解配紅的「答錯了 · 0 分」。改成 `pick()` 與碼表各自量好一次，同一個數字交給 `finishQuestion()`。測試用一個每讀一次就走 1 毫秒的時鐘重現。
- **註解與測試標題的「分數」改掉**：那是 `CONTEXT.md`「計分」那一則的避用詞。
- **票 05 補了一條驗收**：這一行跟著詞條放左欄。原本只寫在這張票上，做票 05 的人看不到。

審查時提到、沒改的：

- `OUTCOMES` 與拼字那張表長得一樣：刻意照抄，兩邊的 key 本來就要分開。
- 拼字判斷收尾看的是 `reason`，這裡看 `picked === null`；拼字另有 `type Outcome` 別名，這裡沒有。兩頁各自的寫法都說得通，不為了對齊去動拼字。
