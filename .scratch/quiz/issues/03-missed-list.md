# 03: 成績頁列出沒答對的卡

Status: done
Type: enhancement
Blocked by: 02

## 要做什麼

一輪結束後，使用者在成績頁頂上三格底下，看到每一張沒答對的卡，知道要回頭記哪幾個。

票 04 也會動成績頁（加「換單字本」）。兩張誰先做都行，後做的那張順手合一下；兩張改的是頁面的不同位置。

## 驗收

- [x] 每一張沒答對的卡一列：詞條（標讀音）、正解的釋義（綠）、使用者點的那個釋義（紅）。
- [x] 逾時的那一列不印紅的，改寫「逾時」，讓「點錯」和「來不及」分得出來。
- [x] 有漢字卻沒標讀音的卡，詞條原樣顯示，不壞版。
- [x] 一題都沒錯時，改印一行全對的話，比照拼字成績頁全對時印的那一行。
- [x] 新增的畫面文字三份翻譯檔都補齊，動手前先讀翻譯檔開頭的規矩。
- [x] 「對的轉綠、錯的轉紅」若要自動測試，比照拼字成績頁的做法：把「這一列算哪一種」拉成不碰 DOM 的純函式來斷言，不斷言 class 名（`ADR-0014`）。
- [x] 冒煙測試走進成績頁時，沒答對的清單也在畫面上。

## 規格出處

`.scratch/quiz/spec.md` 實作決定八。

## 收工紀錄

票 04 還沒做，這張先做，成績頁沒有要合的。

**這一列算哪一種**拉成 `src/ui/quiz-summary.ts` 的 `missedLines()`：回傳詞條底下那兩行，第一行永遠是 `right`（正解），第二行是 `wrong`（點的那個）或 `timeout`（印「逾時」，中性色）。比照拼字的 `toneOf()`，測試斷言它，不斷言 class 名。

**冒煙測試讓問答第一題放著逾時**，再斷言畫面上有這個語言的「逾時」。逾時必定沒答對；點錯哪一個是亂數決定的，靠不住。拿掉清單試過，三種語言都會紅。

維護者拍板的一件事（審查時抓到）：

- **一題都還沒答就按「結束」時，改印「這一輪還沒答任何一題」**，不印「全部答對」。頂上已經是 `0 / 0`，再說全部答對就互相打架。**拼字成績頁一起改**（`spelling.nothingAnswered`），兩頁講一樣的話——這一條超出這張票的範圍，是知情下的決定。

實作時自己拍板的事：

- **逾時的字，中文用「逾時」，英日沿用拼字答題頁那句**（`Time's up`／`時間切れ`）。中文沒借拼字的「時間到」，因為票上點名的是「逾時」。
- **`missedLines()` 多擋一層：點到正解卻沒答對，照逾時畫。** 那只可能是過了時限才點，答題畫面已經先把它換成逾時（票 02），這裡是第二層，不會印出同一個釋義一綠一紅。審查說這條目前走不到，留著的理由是它只有一行。
- **英文全對那句寫 `every card`，不寫 `every question`**：`Question` 是卡片的避用詞。

## 待人工確認

jsdom 沒有排版，下面這幾條只能在瀏覽器與手機上看：

- 正解綠、點錯紅、「逾時」中性色，一眼分得出來。
- 長的釋義在清單裡正常換行，不撐破版面。
- 讀音標在詞條上方，錯十張時整頁捲得動。
