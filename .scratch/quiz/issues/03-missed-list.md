# 03: 成績頁列出沒答對的卡

Status: ready-for-agent
Type: enhancement
Blocked by: 02

## 要做什麼

一輪結束後，使用者在成績頁頂上三格底下，看到每一張沒答對的卡，知道要回頭記哪幾個。

票 04 也會動成績頁（加「換單字本」）。兩張誰先做都行，後做的那張順手合一下；兩張改的是頁面的不同位置。

## 驗收

- [ ] 每一張沒答對的卡一列：詞條（標讀音）、正解的釋義（綠）、使用者點的那個釋義（紅）。
- [ ] 逾時的那一列不印紅的，改寫「逾時」，讓「點錯」和「來不及」分得出來。
- [ ] 有漢字卻沒標讀音的卡，詞條原樣顯示，不壞版。
- [ ] 一題都沒錯時，改印一行全對的話，比照拼字成績頁全對時印的那一行。
- [ ] 新增的畫面文字三份翻譯檔都補齊，動手前先讀翻譯檔開頭的規矩。
- [ ] 「對的轉綠、錯的轉紅」若要自動測試，比照拼字成績頁的做法：把「這一列算哪一種」拉成不碰 DOM 的純函式來斷言，不斷言 class 名（`ADR-0014`）。
- [ ] 冒煙測試走進成績頁時，沒答對的清單也在畫面上。
