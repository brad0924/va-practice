# 01: 問答的出題與計分模組

Status: done
Type: enhancement
Blocked by: None（可以馬上開始）

## 要做什麼

一支不碰畫面的模組，回答問答的四件事：這一輪出哪幾題、每一題的四個選項是什麼、點了之後算對算錯拿幾分、一輪結束時的成績。做完之後畫面上還看不到任何東西，靠自動測試驗收；票 02 拿它接畫面。

形狀比照拼字的出題模組：時間與亂數從外面遞進來，模組內不看時鐘、不取用全域亂數。**不併進拼字那支，也不併進複習那支**，理由見 spec 實作決定一。

用詞照 `CONTEXT.md`：**問答**、**選項**、**一輪**、**計分**、**釋義**。「四選一」「選擇題」「定義」是避用詞，程式裡的名字與註解也不要用。

## 驗收

**開一輪**
- [x] 吃三樣東西：這一輪挑到的卡、整個 app 的卡、亂數。同一組亂數種子跑兩次，卡序與每一題的選項順序完全一樣。
- [x] 挑到的每一張可出題的卡剛好出一次，順序洗過。
- [x] 釋義去除頭尾空白後沒有字的卡不出題。
- [x] 有漢字卻沒標讀音的卡**照常出題**（讀音不是出題條件，spec 實作決定四）。
- [x] 整個 app 湊不出四個不同的釋義時，開出來的一輪一開始就是結束的。

**選項**
- [x] 每一題恰好四個選項，其中恰好一個是這張卡自己的釋義。
- [x] 四個選項去除頭尾空白之後互不相同。兩張卡釋義相同時，不會出現兩個一樣的選項，也不會出現一個跟正解一樣的干擾。
- [x] 干擾從**整個 app** 的卡抽，可以來自沒被挑到的單字本。挑到的本只有兩張卡時仍然出得了題。
- [x] 正解落在四格裡的哪一格是亂的，不是永遠第一格。

**結算與計分**
- [x] 結算吃「點了第幾個選項，或逾時沒點」與「花了幾秒」，回傳推進過的一輪加上這一題的結果。
- [x] 算分**直接呼叫拼字模組那支算分函式**，時限傳 10 秒，不抄一份（spec 實作決定二）。10 秒開成具名常數。
- [x] 點對拿到的分與那支函式在 10 秒時限下的結果一致；點錯 0 分；逾時 0 分。
- [x] 超過時限才點，即使點的是正解也不算對、0 分。
- [x] 一題的結果帶得出：那張卡、四個選項、正解是第幾個、點了第幾個（逾時為沒有）、對不對、幾分。

**成績**
- [x] 帶得出總題數、答對幾題、總分、平均、沒答對的那幾題。
- [x] 平均是總分除以**已經結算過的**題數；一題都沒結算時為 0。
- [x] 中途收工時，還沒出到的那幾題不算進總題數，也不算進沒答對的清單。
- [x] 沒答對的清單包含逾時的題。

**排程**
- [x] 模組沒有 import 複習那支管排程的模組，也沒有 import 資料存放那支模組（`ADR-0021`）。

## Comments

實作在 `core/lib/quiz.ts`，測試在 `core/lib/quiz.test.ts`。票上沒寫、實作時自己拍板的三件事，留給票 02 參考：

- **一輪結束後再結算會丟錯**，丟的是 `AppError('quiz.roundOver')`，比照拼字的 `spelling.roundOver`。`AppError` 只收翻譯檔裡的 key，所以三份翻譯檔各多了一條，並在 `zh-Hant.ts` 開了「問答」分區。票 02 的畫面文字接著往那一區加。
- **干擾純隨機**：整個 app 的釋義去頭尾空白、去重複之後當候選池，每一題扣掉正解、洗牌取三個。每一題都洗一次整池，卡上千張時亂數用量是「題數 × 池子大小」；結果照樣可重現，spec 沒有效能要求，先不優化。
- **洗牌照抄拼字那一份**（拼字當初也是從 `review.ts` 抄來的）。這是第三份 Fisher-Yates；要抽成共用得去改 `spelling.ts` 的對外介面，超出這張票，沒動。

審查時補的一道守門：「點對的分與 `points()` 一致」擋不住有人抄一份一模一樣的曲線，因此另外釘了 `quiz.ts` 必須 `import { points } from './spelling'`、不得自己定義 `points`。
