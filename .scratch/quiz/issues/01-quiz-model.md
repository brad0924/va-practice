# 01: 問答的出題與計分模組

Status: ready-for-agent
Type: enhancement
Blocked by: None（可以馬上開始）

## 要做什麼

一支不碰畫面的模組，回答問答的四件事：這一輪出哪幾題、每一題的四個選項是什麼、點了之後算對算錯拿幾分、一輪結束時的成績。做完之後畫面上還看不到任何東西，靠自動測試驗收；票 02 拿它接畫面。

形狀比照拼字的出題模組：時間與亂數從外面遞進來，模組內不看時鐘、不取用全域亂數。**不併進拼字那支，也不併進複習那支**，理由見 spec 實作決定一。

用詞照 `CONTEXT.md`：**問答**、**選項**、**一輪**、**計分**、**釋義**。「四選一」「選擇題」「定義」是避用詞，程式裡的名字與註解也不要用。

## 驗收

**開一輪**
- [ ] 吃三樣東西：這一輪挑到的卡、整個 app 的卡、亂數。同一組亂數種子跑兩次，卡序與每一題的選項順序完全一樣。
- [ ] 挑到的每一張可出題的卡剛好出一次，順序洗過。
- [ ] 釋義去除頭尾空白後沒有字的卡不出題。
- [ ] 有漢字卻沒標讀音的卡**照常出題**（讀音不是出題條件，spec 實作決定四）。
- [ ] 整個 app 湊不出四個不同的釋義時，開出來的一輪一開始就是結束的。

**選項**
- [ ] 每一題恰好四個選項，其中恰好一個是這張卡自己的釋義。
- [ ] 四個選項去除頭尾空白之後互不相同。兩張卡釋義相同時，不會出現兩個一樣的選項，也不會出現一個跟正解一樣的干擾。
- [ ] 干擾從**整個 app** 的卡抽，可以來自沒被挑到的單字本。挑到的本只有兩張卡時仍然出得了題。
- [ ] 正解落在四格裡的哪一格是亂的，不是永遠第一格。

**結算與計分**
- [ ] 結算吃「點了第幾個選項，或逾時沒點」與「花了幾秒」，回傳推進過的一輪加上這一題的結果。
- [ ] 算分**直接呼叫拼字模組那支算分函式**，時限傳 10 秒，不抄一份（spec 實作決定二）。10 秒開成具名常數。
- [ ] 點對拿到的分與那支函式在 10 秒時限下的結果一致；點錯 0 分；逾時 0 分。
- [ ] 超過時限才點，即使點的是正解也不算對、0 分。
- [ ] 一題的結果帶得出：那張卡、四個選項、正解是第幾個、點了第幾個（逾時為沒有）、對不對、幾分。

**成績**
- [ ] 帶得出總題數、答對幾題、總分、平均、沒答對的那幾題。
- [ ] 平均是總分除以**已經結算過的**題數；一題都沒結算時為 0。
- [ ] 中途收工時，還沒出到的那幾題不算進總題數，也不算進沒答對的清單。
- [ ] 沒答對的清單包含逾時的題。

**排程**
- [ ] 模組沒有 import 複習那支管排程的模組，也沒有 import 資料存放那支模組（`ADR-0021`）。
