# 02: 問答走通一輪

Status: ready-for-agent
Type: enhancement
Blocked by: 01

## 要做什麼

使用者從複習畫面點「問答」，就能從頭玩到尾：一題一題答、看到對錯、一輪結束看到成績、再來一輪。

這張**先不做挑書**：點進來直接拿**全部**單字本出題，挑書頁是票 04 的事。成績頁先只有頂上三格加「再一輪」，沒答對的清單是票 03 的事。

## 驗收

**導覽**
- [ ] 複習畫面標題列右邊擺三顆：「拼字」「問答」「卡片」。
- [ ] 拼字的標題列右邊從「卡片」改成「問答」。
- [ ] 問答的標題列：左「拼字」、中「問答」、右「卡片」。答題與成績頁共用同一條，比照拼字那一條。
- [ ] 卡片畫面左上角的返回從「拼字」改成「問答」。
- [ ] **在 375px 寬量過一次複習標題列**：膠囊變省略號可以；按鈕拆字或標題列換行就停下來回報，不要自己改版面規則（spec 實作決定九）。

**進場**
- [ ] 上一輪還封存著就給成績頁，否則直接用全部單字本開一輪。
- [ ] 出不了題時（沒有可出的卡，或整個 app 湊不出四個不同的釋義），給與拼字「這本是空的」同一個空畫面。

**答題**
- [ ] 上方是詞條，**不標讀音**，旁邊一個 10 秒碼表，樣子與拼字的碼表同一種。
- [ ] 下方四個選項直排、佔滿整行寬度，長的釋義照常換行。選項前**不印數字**。
- [ ] 點下一個選項：碼表停住；其他選項全部點不動；詞條標上讀音；正解轉綠，點錯的轉紅。
- [ ] 逾時：正解轉綠、詞條標上讀音、沒有紅的，記 0 分。
- [ ] 兩種情況都停 1 秒再自動進下一題，這 1 秒不算作答時間。停留長度開成具名常數。
- [ ] 手滑連點兩個選項，同一題只結算一次。
- [ ] 沒有朗讀鈕、沒有鍵盤操作。
- [ ] 中途「結束」鈕直接結算、跳成績頁。

**一輪與成績**
- [ ] 一輪存在 app 狀態裡自己那一格，與拼字那一格分開。
- [ ] 答題途中跳去別的畫面，回來看到的是那一輪的成績頁。
- [ ] 在拼字與問答之間來回切換，兩邊的上一輪各自都還在。
- [ ] 成績頁頂上三格：答對 `9 / 12`、總分、平均，每格底下有自己的標籤。
- [ ] 成績頁有「再一輪」，用同一批卡重開一輪。

**三語與守門**
- [ ] 新增的畫面文字三份翻譯檔都補齊。動手前先讀每一份翻譯檔**開頭的規矩**（英文那份有單複數與名詞順序的規定）。譯名以 `docs/glossary.md` 為準：Quiz／クイズ。
- [ ] 問答的畫面一行都不 import 資料存放那支模組，也不從別的畫面繞路 import 到：擴充拼字現有的那一道守門，不另寫一道。
- [ ] 三語冒煙測試走進問答的答題頁與成績頁，三種語言各一次。
- [ ] 答題的 jsdom 測試：點了一個選項後其他點不動、1 秒之內還停在原題、過了 1 秒換題、逾時後換題且記成逾時、「結束」到成績頁、跳走再回來看到成績頁。不斷言 class 名與版面（`ADR-0014`）。

**實機**
- [ ] 正解綠、點錯紅、讀音標上，這 1 秒在手機上看得清楚。

## 規格出處

`.scratch/quiz/spec.md` 實作決定五（除挑書外）、七、八（頂上三格）、九、十一、十二；測試決定「接縫三」「冒煙測試」。
