# 02: 拼字與問答的標題列改成單字本膠囊，挑書頁與「換單字本」拿掉

Status: needs-triage
Type: enhancement
Blocked by: 01

## 為什麼有這張票

票 01 看原型時，維護者選了分段切換（複習｜拼字｜問答）當拼字與問答的入口。分段切換上已經寫著「拼字」「問答」，標題列中間再印一次就重複了。維護者要把那個位置換成單字本膠囊，跟複習畫面標題列那顆一樣。膠囊在成績頁上就換得了單字本，「換單字本」那顆鈕因此多餘。

這張改的是拼字與問答原本的流程，所以與導覽列分開做（維護者 2026-09-22 選定）。

## 維護者已經定的事（2026-09-22）

1. **拼字與問答每一頁的標題列中間都是單字本膠囊**，包括答題頁。拼字改的是拼字那一組（`app.spellingBooks`），問答改的是問答那一組（`app.quizBooks`），兩組照舊分開、只存本機（`ADR-0021`）。
2. **挑書頁整頁拿掉，進來就開始答題。** 按分段切換的「拼字」，直接用膠囊上的本開一輪。
3. **有封存的上一輪就先給成績頁**，沒有才直接開新的一輪。答到一半跳走，回來看得到那一輪的成績——這條規則不變。
4. **改了膠囊就重開一輪**，答題頁與成績頁同一條規則。答題途中重開，已經答的題不計成績；成績頁上重開，那一輪的成績就不見了。
5. **什麼時候算「改了」：選單收起來那一下。** 在選單裡勾幾本都不動；收起來時勾的跟打開前一樣，就什麼都不做。
6. **有變動時先跳確認視窗**，使用者按確定才重開。
7. **成績頁的「換單字本」拿掉。**「再一輪」留著，給想用同一批重來的人。

## 實作時自己定的事（維護者沒有逐條選，有意見再改）

- **按「取消」就退回打開選單之前的勾選**，本機那一格也不寫。勾選要等按了確定才存。
- **確認視窗只在「有東西會丟掉」時跳**：答題頁與成績頁。一題都出不了的那一頁本來就沒有一輪，改了直接重試，不問。確認的做法沿用 `confirm()`，與 app 其他幾個確認同一套。
- **挑到的本一題都出不了**（本身是空的，或全是有漢字卻沒標讀音的卡）：畫一頁空的提示，講原本挑書頁那一句 `spelling.noCards`（問答是對應那句），標題列膠囊照樣在，人直接在膠囊上換本。至少要勾一本的規矩由 `bookFilter` 鎖最後一本守著，不必另外處理零本。
- 拼字與問答兩邊同一套規則。

## 要做什麼

- `spelling-bar.ts`、`quiz-bar.ts`：中間的 `.bar-title` 換成 `bookFilter`（`variant: 'pill'`）。
- `spelling-home.ts`、`quiz-home.ts`：拿掉挑書那一頁，進來的規則改成「有上一輪給成績頁，沒有就開一輪；開不出來給空的提示頁」。
- 膠囊的 `onOpenChange` 在收起時比對前後勾選；有變動且這一頁有一輪可丟時問一句，確定才寫回本機並重開。
- 成績頁拿掉「換單字本」（`spelling.otherBooks`、`quiz.otherBooks` 三份翻譯檔一起清）。
- 挑書頁那一句說明（`spelling.pickHint` 等）沒有地方放了，一起清掉，除非實作時發現空的提示頁要用。
- 測試：挑書頁的測試（`spelling-books.test.ts`、`quiz-books.test.ts`）大部分要改寫或移走；`app.test.ts` 與三語冒煙測試照新的走法。

## 驗收

- [ ] 拼字與問答每一頁（包括答題頁）標題列中間是單字本膠囊，改的是各自那一組。
- [ ] 按分段切換的「拼字」「問答」，沒有上一輪時直接開始答題；有上一輪時看到成績頁。
- [ ] 在選單裡勾選不會觸發任何事；收起選單時勾選有變才跳確認。
- [ ] 答題頁與成績頁：確定就用新的本重開一輪，取消就退回原本的勾選、本機那一格不變。
- [ ] 挑到的本出不了題時，看到空的提示頁，膠囊還在，換了本直接重試。
- [ ] 成績頁沒有「換單字本」，「再一輪」還在。
- [ ] 375px 寬時標題列不換行、不拆字，三種語言各量一次。
- [ ] 測試不斷言 class 名與版面（`ADR-0014`）。
