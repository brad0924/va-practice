# 編輯畫面改用讀音格，詞條框不再輸入括號

Status: done
Type: enhancement

決策背景見 `.scratch/reading-cells/spec.md`。依賴 `01-reading-cells-model.md`。

## 需求

改造 `src/ui/editor-view.ts`：詞條框只打純文字，下方依偵測到的漢字串自動長出讀音格，並提供切開／合併。

## 現況

單一 `termInput` 直接輸入帶標記的整串（`editor-view.ts:19-24`），下方一行 `SYNTAX_HINT` 教方括號寫法（`editor-view.ts:7`），再下方是即時預覽（`editor-view.ts:26-31`）。儲存時把 `termInput.value.trim()` 直接當 `Card.text`（`editor-view.ts:51,57`）。

## 決定

1. **版面順序：詞條 → 讀音 → 預覽 → 釋義。** 讀音格插在詞條與預覽之間，其餘位置與元素不動。預覽仍是 `renderTerm(組出來的標記字串, true)`，行為與現在一致。

2. **`SYNTAX_HINT` 整行刪除。** 不再需要教方括號寫法。`docs/spec.md` User Story 24（「想在新增畫面上看到語法範例」）隨之失效，由 `03-docs-and-adr.md` 處理。詞條框的 `placeholder` 從 `焦[こ]がす` 改為 `焦がす`。

3. **每個漢字串一組，組內每格是「漢字標籤 + 讀音輸入框」，格與格之間有一道可點的縫。** 縫有兩種狀態，點一下切換：

   ```
   已分（預設）   書  ⊕  留        點 ⊕ → 黏起來
                 [かき] [とめ]

   已黏          書 · 留            點 · → 拆開
                 [かきとめ]
   ```

   單一漢字的串沒有縫，只有一格。

4. **縫是按鈕，要有 `aria-label`。** 沿用 `review-view.ts` 朗讀鈕的無障礙慣例。標籤依狀態給「把書和留合併」／「把書留拆開」這類文字，不能只有符號。觸控目標大小比照 `docs/spec.md` User Story 37（手機上夠大的觸控按鈕）。

5. **讀音輸入框設定與詞條框一致**：`autocapitalize="off"`、`spellcheck=false`。**不設 `inputmode`**——日文假名沒有對應的 `inputmode` 值，設 `kana` 之類的無效值只會被忽略，設 `numeric`／`latin` 反而會害使用者跳到錯的鍵盤。

6. **沒有漢字的詞不長出任何格**，改在讀音區顯示一行灰字「這個詞沒有漢字」。用既有的 `hint` 樣式。不留空白版面，否則使用者會以為東西壞了。

7. **詞條框每次 `input` 事件就重算讀音格**（沿用現有 `refreshPreview` 的即時作風），透過 `rebuildRuns(term, previous)` 保留已填讀音。重算時：

   - **已存在的格不重建 DOM，只增刪差異的部分**——否則正在打字的框會失焦，IME 組字中途會被打斷。
   - 由於 `rebuildRuns` 依漢字內容比對，順著打字時前面的格不會變動，實務上多半只是尾端追加。

8. **貼上帶標記的字串時自動攤回格子。** 在 `input` 事件裡判斷：詞條框內容含合法讀音標記（用 `parseReading` 判斷是否有任何 segment 帶 `reading`）就跑 `toDraft`，把括號從詞條框移除、讀音落進對應格。這條路與「編輯舊卡」共用同一個 `toDraft`。

9. **儲存前跑 `validateDraft`，不通過就顯示在既有的 `error` 元素上，不儲存。** 沿用現有「詞條與釋義都要填」的呈現方式（`editor-view.ts:38,53-56`）。多筆錯誤時全部列出，使用者才不用一條一條試。

10. **`app.upsert()` 收到的仍是 `toMarkup(draft)` 組出來的字串**，`Card` 型別、`newCard()`、`storage.ts`、雲端備份一律不動。

11. **不改樣式檔以外的既有元件。** 讀音區需要的新 class 加在 `src/styles.css`，沿用現有 `field`／`hint`／`labelled` 的命名與間距風格。

## 驗收

**新增（原始痛點）**

- 新增一張 `考え込む`：詞條框全程用日文輸入法打完，下方自動出現 `考`、`込` 兩格，各填 `かんが`、`こ`。**全程不切輸入法、不打任何括號**，儲存後 `Card.text` 為 `考[かんが]え込[こ]む`。
- 新增 `くしゃみ`：讀音區顯示「這個詞沒有漢字」，沒有任何輸入框，可直接儲存。
- 新增 `書留`：預設出現 `書`、`留` 兩格，填 `かき`、`とめ`，儲存為 `書[かき]留[とめ]`。

**切開與合併**

- 新增 `剃刀`：預設兩格，點中間的縫黏起來變一格，填 `かみそり`，儲存為 `剃刀[かみそり]`。
- 新增 `今日中`：預設三格，點第一道縫，變成 `今日` 與 `中` 兩格，填 `きょう`、`じゅう`，儲存為 `今日[きょう]中[じゅう]`。
- 已填 `剃[かみ] 刀[そり]` 時點縫合併 → 該格讀音變成 `かみそり`（不是空的）。
- 已填 `剃刀[かみそり]` 時點縫拆開 → 兩格皆為空。

**編輯舊卡**

- 打開 `帰省[きせい]`：詞條框顯示 `帰省`（無括號），讀音區一格 `帰省` 填著 `きせい`。不按任何鍵直接儲存，`Card.text` 仍為 `帰省[きせい]`。
- 打開 `書留[かきとめ]`：一格。點縫拆開後兩格皆空，填 `かき`、`とめ`，儲存為 `書[かき]留[とめ]`。
- 打開 `ざるを得[え]ない`：詞條框 `ざるを得ない`，讀音區一格 `得` 填著 `え`。
- 打開 `シンポジウム`：讀音區顯示「這個詞沒有漢字」。

**保留與重算**

- 填好 `考[かんが] 込[こ]` 後，把詞條改成 `考え込んだ` → 兩格讀音都還在。
- 再改成 `考え直す` → `考` 保留 `かんが`，`直` 是空格。
- 在詞條前面插入 `深く` → 變成 `深`、`考`、`込` 三格，`考` 與 `込` 的讀音沒有錯位。
- 在讀音框打字時，詞條框不動的情況下焦點不會被搶走；IME 組字中途不被打斷。

**擋錯**

- `今[こん] 日[] 中[ちゅう]` 按儲存 → 擋下並顯示「今日中 這串漢字的讀音要麼全部填、要麼全部留空」，卡片未被儲存。
- `考[kanga]` 按儲存 → 擋下並顯示「考 的讀音要填假名」。
- `考[かんが]` + 片假名讀音 `コ[コーヒー]` → 皆通過。

**貼上**

- 把 `焦[こ]がす` 貼進詞條框 → 詞條框變成 `焦がす`，`焦` 那格自動填入 `こ`。

**不受影響**

- 複習畫面、卡片列表、資料畫面、語音朗讀行為完全不變。
- 刪除按鈕與其確認對話框不變（`editor-view.ts:68-76`）。
- 既有測試全綠。
