# 複習卡片左上角顯示所屬單字本

Status: done
Type: enhancement

## 問題

複習時看得到詞條與釋義，但看不出這張卡住在哪一本單字本裡。卡片列表兩邊都已經在列的右邊印本名（`src/ui/list-view.ts` 的 `.row-book`、`mobile/ui/cards-screen.tsx` 的 `rowBook`），複習畫面沒有對應物。

資料本來就有：`Card.bookId`（`core/lib/types.ts`），不必動任何模型。

## 用詞

這個新東西叫**所屬單字本**——「這張卡住在哪一本」。它與 `CONTEXT.md` 裡的**複習範圍**（標題列那顆膠囊，「我今天要複習哪幾本」）是兩件事，兩邊都會在同一個畫面上出現，不可混用。

## 決定

1. **位置：卡片左上角**，兩個平台都是。用絕對定位浮在卡片上，**不佔一行、不把詞條往下推**。網頁版卡片右上角已經被 `.edit-here`（「編輯」）用同一種手法佔走，左上是對稱的空位；app 版卡片兩個角都空著。
2. **一直都在**：蓋著答案時就看得到，掀開後也還在。版面因此不會在掀答案的那一下跳動。已知代價是本名有機會洩題（單字本若叫「N2 動詞」，蓋著答案時就先知道詞性），維護者知情接受——Anki 也是一直顯示牌組名。
3. **一律顯示**，不看複習範圍勾了幾本。只勾一本時標題列膠囊與卡片上會同時出現同一個名字，接受這個重複，換來只有一條規則、沒有例外。
4. **不能按**，純粹顯示。沿用卡片列表那邊的立場：本名只顯示不可點，搬家在編輯畫面裡做。這次改動只碰版面，不接任何事件。
5. **長本名截斷加省略號**，不換行、不撐破卡片。網頁版比照 `.row-book` 的 `max-width` + `text-overflow: ellipsis`，app 版比照 `numberOfLines={1}` 加寬度上限。
6. **樣式沿用卡片列表那一組**：網頁版走 `var(--muted)`、`0.75rem`；app 版走 `color.tertiaryLabel`、`fontSize.footnote`。它是中性的瀏覽資訊，不與詞條搶注意。
7. **今日份完成與零本兩種畫面不顯示**——那時候沒有卡片，也就沒有所屬單字本。
8. **找不到那本就不顯示**，不填佔位字元。沿用 `list-view.ts` 的 `if (book)` 與 `cards-screen.tsx` 的 `bookName !== undefined`。
9. **輔助使用唸成「單字本：XXX」**，用既有的 `filter.blockLabel`（`core/i18n/`）。光唸本名講不出它是什麼。不新增翻譯 key。
10. **`CONTEXT.md` 的「複習範圍／列表範圍／統計範圍」條目補一句**，指明它與卡片上的所屬單字本是兩件事。不新增條目——「一張卡剛好屬於一本」在「單字本」條目裡已經寫了，這次只是把它畫出來。

## 驗收

- 網頁版與 app 版複習畫面上，卡片左上角都出現這張卡的所屬單字本名稱。
- 蓋著答案時就看得到，掀開答案後仍在同一個位置，詞條不因此上下位移。
- 複習範圍只勾一本時仍然顯示。
- 點（按）本名沒有任何反應。
- 今日份完成與零本兩種畫面上不出現。
- 本名很長時截斷成一行加省略號，不換行、不把卡片撐寬。
- 網頁版右上角的「編輯」按鈕位置不變，與左上角的本名不重疊。
- VoiceOver／螢幕閱讀器唸出來是「單字本：XXX」。
- `CONTEXT.md` 已補上與複習範圍的分界。
- 根目錄 `npm test` 與 `npx tsc --noEmit` 全過；`mobile/` 底下 `npm test` 全過，並在 `mobile/ui/review-screen.test.tsx` 補上涵蓋上述行為的測試。
