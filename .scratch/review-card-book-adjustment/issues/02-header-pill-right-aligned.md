# app 複習標題列的單字本開關改靠右

Status: ready-for-agent
Type: enhancement

## 問題

app 複習畫面的標題列現在是「剩餘 N 張」加上單字本開關那顆膠囊，中間用兩格 `flexGrow: 1` 的彈簧把膠囊往中央推（`mobile/ui/review-screen.tsx` 的 `headerSpacer`）。兩格彈簧一樣長，膠囊的中心因此落在左右剩餘寬度的平均處，往右偏了「剩餘 N 張」那行字的一半——看起來就是「差不多置中但偏右」。

票 `rn-rewrite/09` 拆掉右邊那顆「探針」之後這個偏移變明顯了：探針以前在右邊佔著位置，兩邊差不多一樣寬。

`review-screen.tsx` 裡那段註解已經記著這筆帳，它假設終點是「真的置中」。

## 決定

1. **不置中，改成靠右。** 維護者看過偏移之後決定膠囊乾脆貼齊標題列右緣（2026-09-07）。「剩餘 N 張」留在左邊不動，中間那段空白全給膠囊。
2. **`flexWrap` 必須留著。** 字級調到最大時這一列仍然要換得了行——換不了行時膠囊會被擠出螢幕右邊、按不到，改不了複習範圍（真機踩過，2026-08-26）。因此不用絕對定位。
3. **網頁版不動。** `src/ui/review-view.ts` 那一列是「剩餘 N 張／單字本 ▾／卡片」三格，膠囊左右都有東西，靠不了右；維持 `src/styles.css` 的 `.bar-centered` 置中。兩邊從此刻意不同，理由是兩邊的標題列組成本來就不一樣。
4. **零本畫面不受影響**——那時候膠囊不出現，標題列只有一行「剩餘 0 張」靠左，維持現狀。
5. **`review-screen.tsx` 那段講「差不多置中」的註解要改掉**，改成記錄這次的決定與「為什麼不用絕對定位」。留著會變成指向舊終點的路標。

## 驗收

- app 複習畫面的單字本膠囊右緣，對齊卡片右緣（同一條 `SCREEN_INSET`）。
- 「剩餘 N 張」仍在標題列最左邊。
- 字級調到最大時這一列仍然換行，膠囊完整留在螢幕內且按得到。
- 零本畫面的標題列不變。
- 網頁版複習畫面的標題列不變，膠囊仍然置中。
- `review-screen.tsx` 裡不再有任何句子把「置中」講成這一列的目標。
- `mobile/` 底下 `npm test` 全過。
